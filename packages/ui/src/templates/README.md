# Storybook templates

Layout **shells** for Practical UI: slots and responsive frame only, no single-screen marketing copy. Figma screen mapping and `Pages/*` stories live in [`../pages/README.md`](../pages/README.md).

| Storybook title | Role |
| --- | --- |
| Templates/ApplicationShell | App chrome (header or sidenav) + main |
| Templates/AuthCentered | Centered auth form slot |
| Templates/AuthCard | Card on grid auth form slot |
| Templates/AuthSplitHero | Split layout with hero slot |
| Templates/AuthSplitTestimonial | Split layout with testimonial slot |
| Templates/PracticalTravel | Travel nav, main, optional subscribe, footer |
| Templates/ShopLayout | Shop nav, main, footer slots |
| Templates/WorkoutLayout | Workout nav, main, regions, mobile action |
| Templates/LandingPageLayout | Marketing nav, main, footer |
| Templates/MusicPlayerLayout | Mobile header, sidebar, main column |
| Templates/CollectionLayout | Collector sidebar shell + main |

Shared pieces under `shared/` (e.g. practical travel blocks, application tables) are composed by templates or pages as needed.
