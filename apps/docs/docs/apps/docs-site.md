# Docs Site

This documentation site is built with **Docusaurus 3** using the classic preset.

- **Path:** `apps/docs`
- **Dev URL:** http://localhost:3001
- **Package name:** `docs`

## Content

Markdown files live in `apps/docs/docs/`. The sidebar is autogenerated from the folder structure via `sidebars.ts`:

```ts
const sidebars: SidebarsConfig = {
  docsSidebar: [{ type: "autogenerated", dirName: "." }],
};
```

Use `_category_.json` files in subfolders to group pages in the sidebar.

## Adding a page

1. Create a markdown file under `apps/docs/docs/`, e.g. `development/my-page.md`
2. Add front matter for ordering:

```markdown
---
sidebar_position: 6
---

# My Page

Content here.
```

3. Run `pnpm --filter docs dev` and verify the page appears in the sidebar

## Configuration

| File | Purpose |
| --- | --- |
| `docusaurus.config.ts` | Site title, navbar, footer, preset options |
| `sidebars.ts` | Sidebar structure |
| `src/css/custom.css` | Theme overrides |
| `src/pages/index.tsx` | Homepage |

## Navbar links

The navbar includes links to Storybook (`:6006`) and the web app (`:3000`) for local development. Update URLs in `docusaurus.config.ts` for production deployments.

## Scripts

```bash
pnpm --filter docs dev          # http://localhost:3001
pnpm --filter docs build        # output: apps/docs/build
pnpm --filter docs serve        # preview production build
pnpm --filter docs lint
pnpm --filter docs check-types
```
